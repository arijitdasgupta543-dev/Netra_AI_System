## ২. GitHub-এ কীভাবে তুলবেন (দুটি উপায়)

**উপায় ক (সবচেয়ে সহজ):** এই চ্যাটের সেশনকে আপনার `netra-ai-bd` রিপোতে GitHub access দিন, তারপর আমাকে বলুন — আমি নিজেই push করে দেব। (এখন সেশনে রিপোতে লেখার অনুমতি নেই, তাই আমি push করতে পারিনি।)

**উপায় খ (নিজে):** কম্পিউটারে রিপোর ফোল্ডারে গিয়ে:
```
git am patches/*.patch
git push
```
Lovable GitHub-এর সাথে যুক্ত, তাই push করলেই Lovable-এ কোড চলে যাবে।

## ৩. ডাটাবেস মাইগ্রেশন (জরুরি)

নতুন দুটি ফাইল: `drizzle/migrations/0006_referrals_contacts_vision.sql` ও `0007_rls_initplan.sql`। Push-এর পর Lovable নিজে থেকে না চালালে, Lovable Cloud → Database → SQL editor-এ **০০০৬, তারপর ০০০৭** চালান। এগুলো আগে থেকে থাকা ডেটা মুছে না।

## ৪. Secrets (ঐচ্ছিক)

| নাম | কাজ |
|---|---|
| `SMS_API_URL`, `SMS_API_KEY`, `SMS_SENDER_ID` | বাংলাদেশি bulk-SMS প্রোভাইডার (যেমন BulkSMSBD-ধরনের)। প্রোভাইডারের ডকুমেন্টে প্যারামিটারের নাম মিলিয়ে নিন। না দিলে অ্যাপ WhatsApp/স্লিপ দেখাবে। |
| `LOVABLE_API_KEY` বা `ASSISTANT_API_KEY` (+ `ASSISTANT_API_URL`, `ASSISTANT_MODEL`) | সহায়কের অনলাইন উত্তর। না থাকলে শুধু অফলাইন গাইড চলবে। |
